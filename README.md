# Kakde Agro & Livestock

Premium bilingual farm website starter built with React, Vite and Supabase.

See [SETUP.md](./SETUP.md) before connecting Supabase or deploying.

Features in this starter:
- Responsive public farm website
- English / Marathi language switch
- Agriculture and cow/dairy sections
- Crop list, gallery and farm updates
- Google Maps pin and directions
- Supabase admin login
- Photo uploads and public updates
- Private income/expense ledger with CSV export

Do not deploy publicly until the Supabase setup and single-admin RLS restrictions in SETUP.md are completed.
